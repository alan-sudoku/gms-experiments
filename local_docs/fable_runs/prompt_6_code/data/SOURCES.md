
## D2 (L05: paralinear constants kp', kl)

- Source: E. J. Opila and R. E. Hann Jr., "Paralinear Oxidation of CVD SiC in Water Vapor", J. Am. Ceram. Soc. 80(1), 197-205 (1997). NASA copy NASA-CR-204668: https://ntrs.nasa.gov/api/citations/19970022609/downloads/19970022609.pdf (raw file saved as `raw/opila_hann_1997.pdf`, gitignored).
- Tedmon 1966 (J. Electrochem. Soc. 113(8), 766, doi 10.1149/1.2424115) was found but only its abstract is public via search; its constants were not read.
- Values read (page images checked by eye, pp. 202-203): SiC, 50 % H2O / 50 % O2, 4.4 cm/s, 1200 C. Fig. 4: kp = 2.7e-3 mg^2/(cm^4 h), kl = 5.3e-3 mg/cm^2 h. Table III (this study) kp = 3.80e-3 and 2.72e-3; Table IV (paralinear fit) kl = 5.05e-3 and 5.27e-3 mg SiO2/(cm^2 h). Fig. 1 typical: kp' = 0.50 um^2/h, kl = 0.02 um/h.
- Conversion to the plan's convention (delta*d(delta)/dt = kp'): thickness x = 13.6 um per mg/cm^2 (paper Eq. 16, amorphous silica), so paper kp' (x^2 = kp' t) = 13.6^2 * 2.7e-3 = 0.499 um^2/h (agrees with the paper's Fig. 1 value 0.50); plan kp' = half of that = 6.94e-17 m^2/s. kl: mass loss / density 2.2 g/cm^3 = 0.0241 um/h = 6.69e-12 m/s (paper Fig. 1: 0.02 um/h). Both are inside the planner's UNSURE ranges (kp' 1e-17 to 1e-15, kl 1e-12 to 1e-10). The conversion is the implementer's; UNSURE. Limiting thickness kp'/kl = 10.4 um versus the paper's stated 6.9 um (from all 1200 C data; not reproduced).
- Material is SiC/silica in water vapour at 1200 C, not Cr2O3; it is an anchor system named in L05.
