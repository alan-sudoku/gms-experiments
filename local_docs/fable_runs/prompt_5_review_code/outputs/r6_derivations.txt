== 3. Shape-anisotropy ceiling ==
  unconstrained optimum H' = Ms*p/2 ; reachable iff p*Ms/2 <= Hc <=> p <= [1/2]
  edge branch BH(Hc) = -Ms**2*(p - 1)*(3*p - 1)/4 ; stationary p = [2/3] ; value = 1/12 * mu0 Ms^2
  p <= 1/2 branch maximum: 1/16 * mu0 Ms^2
  Fe65Co35 2.45 T: mu0 Ms^2/12 = 398.1 kJ/m^3; mu0 Ms^2/4 = 1194.2 kJ/m^3
  Fe65Co35 2.43 T: mu0 Ms^2/12 = 391.6 kJ/m^3; mu0 Ms^2/4 = 1174.7 kJ/m^3
  Fe 2.15 T: mu0 Ms^2/12 = 306.5 kJ/m^3; mu0 Ms^2/4 = 919.6 kJ/m^3
  model assumptions: rectangular M(H) loop of each needle, Neel mean-field H_c(p) = H_c(0)(1 - p), coherent rotation;
  incoherent reversal (curling) lowers H_c well below Ms/2 for real needle radii, so 1/12 is an upper bound of this model only.
