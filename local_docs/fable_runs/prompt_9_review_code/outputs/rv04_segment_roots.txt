(a) symbolic sign of f''
  f'' = -K_g/(4*(-a + tau)**(3/2)) + K_s/(4*(-b + tau)**(3/2))
  f'' * alpha^(3/2) beta^(3/2) * 4 = -K_g*beta**(3/2) + K_s*alpha**(3/2)
  so sign f'' = sign(D), D = Ks^2 alpha^3 - Kg^2 beta^3 (Kg, Ks >= 0)
  d/dtau [(tau-a)/(tau-b)] = (a - b)/(b - tau)**2  -> strictly monotone iff a != b
  zero of f'': (tau-a)/(tau-b) = (Kg/Ks)^(2/3) (answer's form); at most one zero when a != b
  a = b: f'' = (Ks - Kg)/(4 (tau-a)^(3/2)), no zero unless Kg = Ks, then f is linear (f == 0 possible)
  Kg = 0: f'' > 0 (convex, <= 2 roots); Ks = 0: f'' < 0 (concave, <= 2 roots)
